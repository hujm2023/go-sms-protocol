# SGIP 1.2 SP 客户端与回执监听器

SP 应用先启动回执监听器，再通过另一条连接完成 `BIND(type=1)`、`SUBMIT` 和 `UNBIND`。随后接收网关发起的 `BIND(type=2)` 回连，校验完整 12 字节提交序列号，确认 `REPORT` 和回连侧的 `UNBIND`。

默认网关地址为 `127.0.0.1:8801`，SP 监听 `127.0.0.1:8802`；监听地址应与网关配置的 `-sp-address` 对应。

所需的两组环境变量、两个终端的启动命令、预期输出和协议说明见 [SGIP 示例说明](../sgip12server/README.md)。
